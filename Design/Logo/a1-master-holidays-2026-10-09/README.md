# BeaverMeter · A1-v2 holiday family

This layout is archived. The current [accessory layout refinement](../a1-layout-refinement-2026-10-09/README.md)
also edits A1-v2 directly, with more connected and grouped props. The
[previous gallery](holiday-collection.png) and every original below are retained.

Every outfit in this family is edited **directly from the approved A1-v2 master**.
The original lower-left emergence, viewing angle, face, scale, crop and sage-teal
background are retained; only seasonal accessories are added.

The classic source is a byte-for-byte copy of [A1-v2](../ip-as-logo-candidates-2026-10-09/A1-v2.png).
There is no centered or transparent intermediate reference. Each seasonal image
uses that same original as its sole ImageGen edit reference.

## Generation records

The built-in ImageGen tool is used for eight independent reference edits. Its
model name is not exposed by the interface. Every returned original is saved
unmodified, with per-image metadata recording its prompt, reference, source path,
native dimensions and SHA-256.

## Application assets

Color runtime exports retain the full square and the master framing. All variants
use one common scale, so accessories cannot shrink the beaver. The menu bar
continues to use one shared monochrome outline, and Finder uses the original
everyday A1-v2 image. Widgets continue to show provider logos.

Variant IDs, manual selections, persistence and calendar dates are unchanged.
Programmers' Day is October 24. Previous centered-head studies are preserved
as historical work in [round-beaver-2026-10-09](../round-beaver-2026-10-09/README.md).
